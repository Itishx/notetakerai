Goal:
Allow users to quickly voice-dump an idea, thought, task, product insight, emotional reflection, or note, then convert it into structured, useful notes and optionally save it to Notion.

Core flow:
1. User clicks/says “Capture This” or “Hey Braino, record this.”
2. App starts recording audio.
3. Show live transcription while the user speaks in the floating transaprent ui as braino listens as he does in sonar pulse 
4. When user stops recording, send transcript to the LLM.
5. LLM analyzes the transcript and converts it into a structured note.
6. Save the structured note inside Braino.
7. If Notion integration is connected, also save/export it to the selected Notion page/database.


Structured note output format:
- Title
- Type: idea / task / journal / emotional dump / product insight / meeting note / random thought
- Summary
- Key points
- Action items
- Open questions
- Related project/person/context if detected
- Priority: low / medium / high
- Tags
- Original transcript
