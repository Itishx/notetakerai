# Braino Knowledge Base

This folder is the memory of the product.

Every meaningful Braino feature, mode, product, release, design decision, or technical change gets documented here when it is built. The public version lives at `/knowledge`; this folder keeps the fuller internal record.

## The rule

Nothing ships undocumented.

For every feature:

1. Add or update its internal document here.
2. Add its public page to the website.
3. Register it in `src/lib/brainoKnowledge.ts`.
4. Include it in **Everything New with Braino**.
5. Explain it in plain, human language before getting technical.
