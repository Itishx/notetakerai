Braino UI Design Kit

Every element below is rebuilt from the shipped extension code (content.js), values untouched: same colors, radii, shadows, blur, and animation timings. Spinners, shimmer, and tick pops are live so you can eyeball the motion.

Each block downloads as a PNG at 3× (on its backdrop, or transparent). Note: browser PNG capture cannot bake in backdrop-filter blur, so exported glass keeps its translucency but not the blur. Blur specs are listed under each element.

Turning frame sequences into transparent video

Browsers cannot export alpha video directly, so the sequences above are the pro handoff: After Effects and Premiere import a PNG sequence as footage with alpha (File → Import, tick "PNG Sequence"). To hand off an actual transparent video file instead, run the frames through ffmpeg — every ZIP includes a README with this command:

ffmpeg -framerate 30 -i braino-walk-wave_%03d.png -c:v prores_ks -profile:v 4444 -pix_fmt yuva444p10le braino-walk-wave.mov
That produces a ProRes 4444 .mov with real alpha (the industry-standard transparent video). True "transparent MP4" (HEVC + alpha) only plays on Apple devices; ProRes or the raw PNG sequence is what motion tools want.
